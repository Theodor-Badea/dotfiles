# How to use with stow
1. Install stow
```bash
# Arch / Endeavour / Manjaro
sudo pacman -S stow

# Fedora
sudo dnf install stow

# Ubuntu / Debian
sudo apt install stow
```

2. Link them to the .config directory
```bash
stow -t ~ dirname
```
